# Security and data-loss reports

This is a local application, not an encrypted recipe vault. Anyone with access
to the browser profile may access its data. It provides no cloud authentication,
backup service or encryption guarantee.

Avoid uploading real recipe databases to public issues. Use minimal fictional
fixtures. For a security-sensitive issue, use GitHub's private vulnerability
reporting if enabled by the repository owner; otherwise ask the owner for a
private reporting channel without publishing exploit details or private data.
No email address is assumed by this document.

Before troubleshooting storage errors, export JSON. Do not clear site data or
reset the database without a backup. File-origin behavior and browser storage
policies differ; persistent-storage permission cannot replace a downloaded copy.
