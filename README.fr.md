Calculez le coût réel de vos recettes, produits, pertes, main-d’œuvre et marge. Les données restent dans votre navigateur, sans compte ni serveur.

## Fonctionnalités / Funktionen / Возможности

- matériaux et prix d’achat
- recettes imbriquées et produits
- mise à l’échelle par rendement ou dimensions
- PDF, sauvegardes JSON et liste d’achats
- interface en neuf langues
