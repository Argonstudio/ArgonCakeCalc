Calcola il costo reale di ricette e prodotti, inclusi scarti, lavoro, energia e margine. I dati restano nel browser, senza account né database cloud.

## Fonctionnalités / Funktionen / Возможности

- materiali e prezzi di acquisto
- ricette annidate e prodotti
- scalatura per resa o dimensioni
- PDF, backup JSON e lista della spesa
- interfaccia in nove lingue
