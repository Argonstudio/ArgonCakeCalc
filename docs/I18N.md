## Supported interfaces

English (en), Russian (ru), French (fr), German (de), Norwegian Bokmål (nb),
Spanish (es), Italian (it), Simplified Chinese (zh) and Japanese (ja).
There are 534 static literal fragments per catalog. These are fragments from
labels, messages, accessibility text, help, sample data and PDF sections, not
534 full pages or professionally certified translations. Native review welcome.

JSON files in `locales/` are the editable source. The Russian file maps source
keys to themselves; other files have exactly the same keys. Never insert markup
or straight double quotes into catalog values: they may occur inside static HTML
attribute fragments. Use typography quotes where needed. Preserve math, units,
percent signs, deliberate whitespace and meaning, especially UPWARD rounding.

Build: `python tools/build-locales.py`, then rebuild standalone/SW. `--check`
rejects a stale generated asset. The browser loads only the embedded/local asset;
there is no runtime fetch of translation JSON or translation API.

## Literal isolation

`T('source literal')` translates only that literal. `T.l` is a tagged-template
helper: it translates each static chunk and joins dynamic values WITHOUT
translation. This protects record names such as a Russian word shown in the
English interface. It also avoids changing user recipe instructions or numbers.
Never translate whole user-populated DOM trees or finished message strings.
`hydrate()` is only for the initial static document, before record rendering.
The helper does NOT escape user HTML; use the app's existing `esc` separately.

Catalog keys are the trimmed human portions of literal chunks, split on HTML
punctuation and quote delimiters. Original whitespace is preserved on lookup.
When introducing a new literal, add its exact resulting key to ALL catalogs.
`CakeI18n.missing` records untranslated source fragments for browser QA.
Templates immediately following a return statement must keep a token separator:
`return T.l` followed by the template, not a combined identifier `returnT`.

## Selection and persistence

On first browser load, a valid saved language wins; otherwise the interface uses
English regardless of navigator.language. Node also defaults to English.
Russian error-text regression tests explicitly select ru. Tests can set
`CakeI18n.language` BEFORE loading core constants. The actual UI switches via
reload so constants, units and role labels initialize consistently.

Language preference: localStorage `argon-cakecalc-language`. A switch checks the
draft, flushes valid pending writes, asks for confirmation, saves the preference
and reloads. It does not rewrite names/categories, prices, number locale or
currency already stored in the database. New record defaults and optional sample
names are created in the current interface language and become ordinary data.

First-use currency/number defaults: en USD/en-US; ru RUB/ru-RU; fr EUR/fr-FR;
de EUR/de-DE; nb NOK/nb-NO; es EUR/es-ES; it EUR/it-IT; zh CNY/zh-CN; ja JPY/ja-JP.
Additional currencies: GBP, CHF, CAD, AUD, KZT, BYN, UAH. Currency display names
come from local browser Intl data, not a server. Selection does not perform FX.
All currencies retain the same hundredth-based financial rounding and two-place
costing display, including JPY.

## Fonts and script scope

Web UI uses system fonts. PDF includes local Latin/Cyrillic and 30,445-character
BMP CJK fonts; no CDN. The writer switches fonts when a supported character is
missing from the base font. This supports normal Chinese/Japanese text and user
names; unsupported emoji/supplementary characters may become `?`. CJK fonts are
large and make CJK PDFs larger. See THIRD_PARTY.md for OFL notices.

## Fixed brand, seeds and calendar

The visual wordmark АргонТорт and its Cyrillic А monogram are protected from initial text hydration. The project/repository name remains ArgonCakeCalc. New database material categories are English seeds: Ingredients, Decorations, Packaging, Consumables, Other. Existing category data is not renamed.

The custom offline calendar formats month names, weekday labels, accessible full dates and day numbers using Intl with the selected UI language, independently of the saved financial number locale or OS calendar. The week begins Monday. Dates are stored and can be typed as YYYY-MM-DD. The popup supports keyboard arrows, native dialog focus containment and Escape dismissal. Navigation/close labels are bundled in all catalogs.

## Field guidance and detailed help

Short hints and four detailed dialogs (pricing, yield scaling, fitting dimensions, taking yield from geometry) are bundled in all nine catalogs. Hints are visible and linked via aria-describedby. Native dialogs provide focus containment, Escape dismissal and focus return; there is no hover-only dependency.
