ArgonCakeCalc は、パティシエやお菓子づくりを仕事にする人のためのプログラムです。主な機能：レシピの作成、材料リストの保存、商品の設計（多段ケーキの可視化を含む）、そして原価と利益の即時計算。作成したレシピや商品は PDF としてダウンロードできます。プログラムはローカルで動作し、インストールもインターネット接続も不要です。

アカウント、サブスクリプション、クラウドデータベースは必要ありません。レシピや価格は、お使いのデバイスのブラウザ内に残ります。

## クイックスタート

プログラムは 1 つのファイルだけです。何もインストールする必要はありません。

1. [GitHub の ArgonCakeCalc リポジトリ](https://github.com/Argonstudio/ArgonCakeCalc)を開き、ファイル [`ArgonCakeCalc.html`](ArgonCakeCalc.html) に移動します。
2. ファイルのページでダウンロードアイコン（**Download raw file**）をクリックし、ずっと置いておけるフォルダーに保存します。
3. 保存したファイルを、パソコン、タブレット、スマートフォンの最新のブラウザーで開きます。

ファイルにはプログラム、すべての翻訳、スタイル、PDF 用フォントがすでに含まれているため、ダウンロード後はインターネットなしで動作します。

ダウンロードしたくない場合は、ウェブサイトを開いてください：**ТУТ ССЫЛКА НА САЙТ**。安定した HTTPS アドレスでは、初回の読み込み後にオフラインで使えるよう準備されることもあります。

インターフェースは英語で開きます。言語はプログラム内で切り替えられます：ロシア語、フランス語、ドイツ語、ノルウェー語（ブークモール）、スペイン語、イタリア語、簡体字中国語、日本語。

> [!WARNING]
> **データは HTML ファイルの中ではなく、ブラウザーに保存されます。** ファイルを移動したり名前を変更したりした場合、ブラウザーを変えた場合、ブラウザーのデータを消去した場合、またはプライベートモードで作業した場合、レシピや価格にアクセスできなくなる可能性があります。ファイルは同じ場所に置き、常に同じブラウザーで開き、JSON バックアップを定期的にエクスポートしてください。詳細は[データとバックアップ](#データとバックアップ)をご覧ください。

## できること

- **材料。** 材料、デコレーション、包装、消耗品のカタログを管理できます。各項目に、パッケージの価格、パッケージあたりの量、単位、カテゴリ、必要に応じて密度を入力します。グラム、キログラム、ミリリットル、リットルに対応しています。質量と体積は密度がわかっている場合にのみ相互に換算され、個数が自動的に重量へ換算されることはありません。
- **レシピと構成部品。** 仕上がり量、調理時のロス、手順、材料の行を含むレシピを作成できます。構成部品には材料のほか、別のレシピも指定できます。フィリングにクリームを、クリームにシロップを含めることができます。入れ子のレシピは原材料まで展開され、同じ構成部品は 1 つのわかりやすい購入リストにまとめられます。材料の価格を変更すると、それに依存するすべてのレシピと商品が自動的に再計算されます。
- **商品ビルダー。** スポンジ、フィリング、クリーム、シロップ、コーティング、デコレーション、包装を組み合わせて商品を作ります。商品を保存し、テンプレートとして複製し、保存済みの計算を変えずに複数の販売価格を比較できます。
- **完全な原価。** 人件費、電気代、配送費、包装、その他の費用、ロスの予備を加え、掛け率または目標利益率、必要であれば最低利益を設定します。原価にはパッケージのうち実際に使った分だけが含まれ、購入リストではパッケージ数が切り上げられます。
- **拡大縮小。** 目標の仕上がり量、または丸型ケーキの直径と高さに合わせてレシピを再計算します。材料の各行は、比例して、面積に応じて拡大縮小したり、固定のままにしたり、整数の個数に切り上げたりできます。ケーキの形状は目安の見積もりであり、構造強度や食品安全の計算ではありません。
- **PDF、購入リスト、バックアップ。** 材料、原材料、手順、原価、推奨価格、寸法を含む PDF を書き出せます。生産用、または注文を準備する人に渡すための購入リストをダウンロードできます。ブラウザーやデバイス間でデータを移すために、完全な JSON バックアップを保存できます。

## 最初の計算

初回起動時は、空の作業スペースか、架空のデモから始められます。デモは作業の流れをすぐに把握するためのもので、価格は例であり、実際の市場価格ではありません。

1. 実際に支払っている仕入れ価格を追加します。
2. レシピを作成し、仕上がり量とロスを入力します。
3. 商品を組み立て、寸法または人数分（個数）を設定します。
4. 人件費、電気代、包装、その他の費用を追加します。
5. 掛け率と目標利益率のそれぞれで販売価格を比較します。
6. PDF と購入リストを書き出し、JSON バックアップを保存します。

## 価格の計算方法

- ロス後の仕上がり量 ＝ 入力した仕上がり量 × ロス後に残る割合。
- 掛け率による価格 ＝ 完全な原価 × (1 + 掛け率 % ÷ 100)。
- 目標利益率による価格 ＝ 完全な原価 ÷ (1 − 利益率 % ÷ 100)。
- 推奨販売価格は、選択した通貨の精度に合わせて切り上げられます。
- 計算は正確です。途中の結果は早い段階で丸められません。
- 入れ子のレシピは原材料の数量まで展開されます。
- 購入リストではパッケージが切り上げられ、原価では実際に消費した分だけが計上されます。
- 通貨を選んでも、変わるのは表記と精度だけです。為替レートによる換算は行いません。

計算式と前提は[計算ルール](docs/CALCULATIONS.md)に記載されています。

## データとバックアップ

材料、レシピ、商品、設定は、ブラウザーの IndexedDB に、サイトのアドレスまたはファイルの場所ごとに別々に保存されます。インターフェースの言語は小さなローカル設定として保存されます。アカウント、アクセス解析、隠れたクラウド同期、サーバー側のレシピデータベースはなく、ユーザーの操作なしに何かが送信されることもありません。

JSON バックアップを定期的にエクスポートし、HTML ファイルを移動または名前変更する前には必ず行ってください。ブラウザーのデータの消去、プライベートモード、サイトのアドレスの変更、ファイルの移動、デバイスの紛失により、ローカルデータベースにアクセスできなくなることがあります。ローカルファイル（`file://`）の保存動作はブラウザーによって異なる場合があり、日常的な利用には安定した HTTPS アドレスのほうが確実です。ブラウザーの永続ストレージの許可は、バックアップの代わりにはなりません。

## 制限事項

PDF はお使いのデバイス上で作成され、印刷ダイアログもサーバーへのアップロードもありません。ラテン文字、キリル文字、中国語、日本語に対応しています。中国語と日本語のフォントによりファイルサイズが大きくなります。非対応の絵文字や珍しい文字は、PDF で `?` と表示されることがあります。

このプログラムには、在庫管理、税務モジュール、為替レート、注文管理、クラウドアカウント、デバイス間の同期、ケーキの構造的な安全性の計算は含まれていません。生産や顧客への価格提示に使う前に、結果をご自身で確認してください。
