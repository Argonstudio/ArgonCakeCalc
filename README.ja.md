## アプリケーションの機能

- **材料管理。** 材料、デコレーション、包装材、消耗品のカタログを管理できます。各項目に、パッケージ価格、パッケージ内容量、単位、カテゴリ、必要に応じて密度を設定します。グラム、キログラム、ミリリットル、リットルに対応しています。質量と体積の換算は密度が分かっている場合に限り行われ、個数が自動的に重量へ換算されることはありません。
- **レシピと構成要素。** 出来高、調理時のロス、手順、材料明細を含むレシピを作成できます。構成要素には材料または別のレシピを指定できます。たとえばフィリングにクリームを含め、クリームにシロップを含めることができます。入れ子になったレシピは基礎材料まで展開され、同じ構成要素は分かりやすい買い物リストにまとめられます。材料価格を変更すると、それに依存するすべてのレシピと製品が自動的に再計算されます。
- **製品ビルダー。** スポンジ、フィリング、クリーム、シロップ、コーティング、デコレーション、包装材を組み合わせて完成品を作成できます。製品の保存やテンプレートとしての複製、保存済みの計算を変更せずに複数の販売価格を比較することもできます。
- **総原価。** 人件費、電気代、配送費、包装費、その他の費用、ロスへの予備費を追加できます。そのうえで、上乗せ率または目標利益率を設定し、必要に応じて最低利益も指定できます。原価には実際に使用したパッケージの割合だけが含まれ、買い物リストのパッケージ数は切り上げられます。
- **スケーリング。** 目標出来高、または丸いケーキの直径と高さに合わせてレシピを再計算できます。各材料行は、比例、表面積に基づく調整、固定、または個数単位への切り上げを選べます。ケーキの幾何学的な計算は補助的な目安であり、構造強度や食品安全性を保証する工学的計算ではありません。
- **PDF、買い物リスト、バックアップ。** 材料、原材料、手順、原価、推奨価格、サイズを含むPDFをエクスポートできます。製造用、または注文を準備する担当者に渡すための買い物リストをダウンロードできます。ブラウザーや端末間でデータを移すために、完全なJSONバックアップを保存できます。

## はじめての計算

初回起動時には、空の作業スペースから始めるか、架空のデモデータを読み込めます。デモは操作の流れをすばやく理解するのに役立ちますが、価格は例示用であり、実際の市場価格ではありません。

1. 実際に支払っている仕入れ価格を登録します。
2. レシピを作成し、出来高とロスを入力します。
3. 製品を組み立て、サイズまたは人数を設定します。
4. 人件費、電気代、包装費、その他の費用を追加します。
5. 上乗せ率と目標利益率による販売価格を比較します。
6. PDFと買い物リストをエクスポートし、JSONバックアップを保存します。

## 価格の計算方法

- ロス後の出来高 = 入力した出来高 × ロス後に残る割合。
- 上乗せ率による価格 = 総原価 × (1 + 上乗せ率 % ÷ 100)。
- 目標利益率による価格 = 総原価 ÷ (1 − 利益率 % ÷ 100)。
- 推奨価格は、選択した通貨の表示精度に合わせて切り上げられます。
- 計算は正確に行われ、中間結果を事前に丸めることはありません。
- 入れ子になったレシピは、基礎材料の数量まで展開されます。
- 買い物リストではパッケージ数を切り上げますが、原価には実際に使用した割合だけを計上します。
- 通貨の選択で変わるのは通貨記号と表示精度だけです。為替レートによる通貨換算は行いません。

数式と前提条件は[計算ルール](docs/CALCULATIONS.md)に記載されています。

## データとバックアップ

材料、レシピ、製品、設定はブラウザーのIndexedDBに保存され、ウェブサイトのアドレスまたはファイルの場所ごとに分離されます。インターフェースの言語は小さなローカル設定に保存されます。アカウント、分析機能、非表示のクラウド同期、サーバー上のレシピデータベースはありません。ユーザーの操作なしにデータが送信されることはありません。

JSONバックアップを定期的にエクスポートしてください。HTMLファイルを移動または改名する前には必ずバックアップを作成してください。ブラウザーデータの消去、プライベートブラウジング、ウェブサイトアドレスの変更、ファイルの移動、端末の紛失によって、ローカルデータベースにアクセスできなくなる場合があります。ローカルファイル（`file://`）のストレージ動作はブラウザーによって異なることがあります。日常的に使う場合は、安定したHTTPSアドレスの方が信頼性があります。ブラウザーの永続ストレージを許可しても、バックアップの代わりにはなりません。

## 制限事項

PDFは印刷ダイアログを開いたりサーバーに送信したりせず、お使いの端末上で生成されます。ラテン文字、キリル文字、中国語、日本語に対応しています。中国語と日本語のフォントはアプリケーションのファイルサイズを大きくします。未対応の絵文字や珍しい文字はPDFで `?` と表示される場合があります。

在庫管理、税務モジュール、為替換算、注文管理、クラウドアカウント、端末間同期、ケーキの構造安全性に関する工学的計算は含まれていません。製造に使用したり、お客様に価格を提示したりする前に、結果をご自身で確認してください。
