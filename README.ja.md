## Fonctionnalités / Funktionen / Возможности

- 材料と仕入れ価格
- 入れ子レシピと商品構成
- 出来高または型の寸法による拡大縮小
- PDF、JSONバックアップ、買い物リスト
- 9言語のインターフェース
