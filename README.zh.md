ArgonCakeCalc 是一款帮助烘焙师和糕点师的程序。主要功能：创建配方、保存原料清单、设计产品（包括多层蛋糕，并可视化展示），并立即得到成本和利润的计算结果。创建的配方和产品可以下载为 PDF。程序在本地运行，无需安装，也无需联网。

无需账户、订阅或云端数据库。您的配方和价格保留在您设备的浏览器中。

## 程序能做什么

- **材料。** 建立原料、装饰、包装和耗材的目录。为每个条目填写包装价格、每包数量、单位、类别，必要时还可填写密度。支持克、千克、毫升和升。只有在已知密度时，质量和体积才会相互换算；件数不会被自动换算成重量。
- **配方和组件。** 创建包含产出量、制作损耗、制作说明和配料行的配方。组件可以是材料，也可以是另一个配方：馅料可以包含奶油，奶油可以包含糖浆。嵌套的配方会被展开到原材料，相同的组件会合并为一份清晰的采购清单。材料价格变化时，所有依赖它的配方和产品都会自动重新计算。
- **产品构建器。** 用蛋糕坯、馅料、奶油、糖浆、淋面、装饰和包装组合出一个产品。可以保存产品、将其复制为模板，并在不改变已保存核算的情况下比较不同的销售价格。
- **完整成本。** 加入人工、电费、配送费用、包装、其他费用和损耗储备，然后设置加价或目标利润率，必要时设置最低利润。成本只计入包装中实际用掉的部分，而采购清单中的包装数量会向上取整。
- **缩放。** 按目标产出量，或按圆形蛋糕的直径和高度重新计算配方。每个配料行可以按比例缩放、按面积缩放、保持固定，或向上取整为整件。蛋糕的几何尺寸只是辅助估算，不是结构强度或食品安全的计算。
- **PDF、采购清单和备份。** 导出包含配料、原材料、制作说明、成本、建议售价和尺寸的 PDF。下载采购清单用于生产，或交给准备订单的人。保存完整的 JSON 备份，以便在不同浏览器或设备之间转移数据。

## 第一次计算

首次启动时，您可以从空白工作区开始，也可以使用虚构的演示数据。演示可以快速展示操作流程，但其中的价格只是示例，并不代表真实市场价格。

1. 添加您实际支付的采购价格。
2. 创建配方，并填写产出量和损耗。
3. 组合产品，并设置尺寸或份数。
4. 加入人工、电费、包装和其他费用。
5. 比较按加价和按目标利润率得出的销售价格。
6. 导出 PDF 和采购清单，然后保存 JSON 备份。

## 价格如何计算

- 损耗后的产出量 = 输入的产出量 × 损耗后剩余的百分比。
- 按加价的价格 = 完整成本 × (1 + 加价 % ÷ 100)。
- 按目标利润率的价格 = 完整成本 ÷ (1 − 利润率 % ÷ 100)。
- 建议售价按所选货币的精度向上取整。
- 计算是精确的：中间结果不会被提前取整。
- 嵌套的配方会被展开为原材料数量。
- 采购清单中的包装向上取整；成本中只计入实际消耗的部分。
- 选择货币只改变符号和精度，不进行汇率换算。

公式和假设见[计算规则](docs/CALCULATIONS.md)。

## 您的数据和备份

材料、配方、产品和设置保存在浏览器的 IndexedDB 中，每个网站地址或文件位置各自独立。界面语言保存为一个很小的本地设置。没有账户、统计分析、隐藏的云同步或服务器端配方数据库，未经您操作，任何内容都不会被发送出去。

请定期导出 JSON 备份，并且在移动或重命名 HTML 文件之前一定要导出。清除浏览器数据、隐私模式、网站地址变化、移动文件或设备丢失，都可能导致无法访问本地数据库。本地文件（`file://`）的存储在不同浏览器中的表现可能不同；日常使用时，稳定的 HTTPS 地址更可靠。浏览器的持久存储权限不能替代备份。

## 限制

PDF 在您的设备上生成，不会弹出打印对话框，也不会上传到服务器。支持拉丁字母、西里尔字母、中文和日文；中文和日文字体会增大文件体积。不支持的 emoji 和生僻字符在 PDF 中可能显示为 `?`。

程序不包含库存管理、税务模块、汇率、订单、云账户、跨设备同步，也不包含蛋糕结构安全的计算。在用于生产或向客户报价之前，请自行核对结果。
