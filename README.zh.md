## 程序功能

- **材料管理。** 管理原料、装饰品、包装和耗材目录。每个项目可设置包装价格、包装内数量、计量单位、类别，以及必要时的密度。支持克、千克、毫升和升。只有已知密度时才会进行质量与体积换算；件数不会被自动换算成重量。
- **配方与组件。** 创建包含产量、制作损耗、操作说明和配料明细的配方。组件既可以是材料，也可以是另一个配方：馅料可以包含奶油，奶油也可以包含糖浆。嵌套配方会展开到最基础的材料，相同组件会合并到一份清晰的采购清单中。材料价格变化时，所有依赖该材料的配方和产品都会自动重新计算。
- **产品构建器。** 使用蛋糕胚、馅料、奶油、糖浆、淋面、装饰和包装组合成品。可以保存产品、复制为模板，并比较不同销售价格，而不会更改已保存的计算结果。
- **完整成本。** 添加人工、电费、配送费用、包装、其他支出和损耗预留金，然后设置加价率或目标利润率，并可按需设置最低利润。成本只计入实际使用的包装份额；采购清单中的包装数量则向上取整。
- **比例缩放。** 根据目标产量，或圆形蛋糕的直径和高度重新计算配方。每一项配料都可以按比例缩放、按表面积缩放、保持固定，或向上取整为整数件。蛋糕几何尺寸仅用于辅助估算，并非结构强度或食品安全的工程计算。
- **PDF、采购清单与备份。** 导出包含配料、原材料、操作说明、成本、建议售价和尺寸的 PDF。下载用于生产的采购清单，也可以将清单交给负责准备订单的人。保存完整 JSON 备份，以便在不同浏览器或设备之间迁移数据。

## 第一次计算

首次启动时，你可以从空白工作区开始，也可以载入虚构示例。示例能快速展示操作流程，但其中的价格仅为演示数据，并不代表真实市场价格。

1. 添加你实际支付的采购价格。
2. 创建配方并填写产量和损耗。
3. 组合产品并设置尺寸或份数。
4. 添加人工、电费、包装和其他费用。
5. 比较按加价率和目标利润率计算的销售价格。
6. 导出 PDF 和采购清单，然后保存 JSON 备份。

## 价格计算方式

- 损耗后的产量 = 输入产量 × 损耗后剩余百分比。
- 按加价率计算的价格 = 完整成本 × (1 + 加价率 % ÷ 100)。
- 按目标利润率计算的价格 = 完整成本 ÷ (1 − 利润率 % ÷ 100)。
- 建议价格会根据所选货币的精度向上取整。
- 计算结果保持精确：中间结果不会提前舍入。
- 嵌套配方会展开为基础材料的实际用量。
- 采购清单中的包装数量向上取整；成本计算只计入实际消耗的部分。
- 选择货币只会改变货币符号和精度，不会根据汇率进行货币转换。

公式和假设详见[计算规则](docs/CALCULATIONS.md)。

## 你的数据与备份

材料、配方、产品和设置保存在浏览器的 IndexedDB 中，并按每个网站地址或文件位置分别存储。界面语言保存在一个很小的本地设置中。程序没有账户、分析追踪、隐藏的云同步或服务器端配方数据库。未经你的操作，任何数据都不会被发送出去。

请定期导出 JSON 备份，并务必在移动或重命名 HTML 文件之前进行备份。清除浏览器数据、使用隐私浏览模式、更改网站地址、移动文件或设备丢失，都可能导致本地数据库无法访问。不同浏览器对本地文件（`file://`）的存储行为可能不同；长期使用时，稳定的 HTTPS 地址更加可靠。允许浏览器持久化存储并不能替代备份。

## 限制

PDF 在你的设备上生成，不会打开打印对话框，也不会上传到服务器。支持拉丁字母、西里尔字母、中文和日文。中文和日文字体会增加程序文件的大小。不支持的 emoji 和罕见字符在 PDF 中可能显示为 `?`。

程序不包含库存管理、税务模块、汇率换算、订单管理、云账户、设备间同步，也不提供蛋糕结构安全方面的工程计算。在用于生产或向客户报价之前，请自行核对计算结果。
