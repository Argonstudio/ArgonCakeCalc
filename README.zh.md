计算配料、配方和产品的真实成本，包括损耗、人工、能源和目标利润率。数据保存在浏览器中，无需账户或云端数据库。

## Fonctionnalités / Funktionen / Возможности

- 材料和采购价格
- 嵌套配方与产品组合
- 按产量或尺寸缩放
- PDF、JSON 备份和采购清单
- 九种界面语言
