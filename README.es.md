Calcula el coste real de recetas y productos, incluyendo mermas, trabajo, energía y margen. Tus datos permanecen en el navegador, sin cuenta ni base de datos en la nube.

## Fonctionnalités / Funktionen / Возможности

- materiales y precios de compra
- recetas anidadas y productos
- escalado por rendimiento o dimensiones
- PDF, copias JSON y lista de compras
- interfaz en nueve idiomas
